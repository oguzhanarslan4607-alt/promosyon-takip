# Promosyon Takip

Promosyon ürünlerini, stok miktarlarını, ofisleri, personelleri ve ürün teslimatlarını takip etmek için tek sayfalık uygulama.

## Kullanım

`index.html` dosyasını tarayıcıda açın. Ürün kodu ve adı zorunludur. Teslimat kaydedildiğinde stok otomatik düşer ve imza formu yazdırmaya açılır.

Kayıtlar kullanılan tarayıcıda saklanır. **Yedeği indir** düğmesiyle JSON yedeği alıp başka tarayıcıda **Yedek yükle** ile aktarabilirsiniz.

Bu sürümde ortak çevrimiçi veritabanı bulunmaz; GitHub deposu uygulama dosyalarını barındırır.
